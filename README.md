# القرآن الكريم — تطبيق أندرويد

تطبيق أوفلاين كامل (القرآن + الترجمة + الأذكار + مواقيت الصلاة + ١٢ أذان) داخل
ملف HTML واحد، ملفوف في تطبيق أندرويد. نفس طريقة «مطبخ البنات»: GitHub Actions
بتبني الـ APK على كل دفعة إلى `main` وتنشره في وسم `latest`.

## النشر (مرة واحدة، من المتصفح — موبايل أو كمبيوتر)

1. اعمل حساب على github.com (مجاني).
2. **New repository** — الاسم مثلًا `quran-app` — اختار Private أو Public — **Create repository**.
3. في الصفحة الجديدة: **uploading an existing file** — اسحب محتوى هذا المجلد
   (المجلدات `app` و`.github` والملفات اللي جنبهم)، واكتب في الأسفل رسالة
   «أول نسخة» ثم **Commit changes**.
   موقع GitHub بيقبل كل ملف لحد ٢٥ ميجا، و`index.html` حجمه ١٤.٢ ميجا — فتمام.
4. افتح تبويب **Actions** — هتلاقي «بناء APK» بيشتغل لوحده، خد ٤–٦ دقايق.
5. لما يخلص: **Releases** ← وسم `latest` ← `app-debug.apk` ← نزّله على الموبايل
   وثبّته (الموبايل هيسأل: السماح بالتثبيت من هذا المصدر — اسمح).

رابط الإصدار هيكون بالشكل:

    https://github.com/<اسم-حسابك>/quran-app/releases/tag/latest

والرابط ده ثابت — أي نسخة جديدة ترفعها بتستبدل الـ APK في نفس المكان.

## التحديث

عدّل `app/src/main/assets/index.html` وارفع الملف تاني (Add file ← Upload files)
وزوّد `versionCode` و`versionName` في `app/build.gradle`. الـ Actions هتبني من
جديد وتنشر في نفس `latest`.

## بنية المشروع

- `app/src/main/assets/index.html` — التطبيق نفسه (ملف واحد، كله أوفلاين).
- `app/src/main/java/com/aya/quran/MainActivity.java` — شاشة WebView بتفتح
  الصفحة من داخل التطبيق (مش من النت)، وبتحفظ ملف النسخة الاحتياطية في Downloads.
- `.github/workflows/build-apk.yml` — البناء والنشر التلقائي.

## حدود معروفة

التطبيق بيشتغل أوفلاين بالكامل للقرآن والمواقيت والأذكار. الأذان بيشتغل والتطبيق
مفتوح أو في الخلفية، لكن **مش** وهو الموبايل مقفول — ده محتاج خدمة أندرويد
أصلية (alarm)، مش صفحة ويب. نفس الحد موجود في نسخة المتصفح.
